# Hướng dẫn thiết lập ban đầu

\- Khi bắt đầu sử dụng phần mềm, bạn cần thực hiện lần lượt 3 bước sau để hoàn tất thiết lập ban đầu. Ngoài ra thiết lập ban đầu sẽ giúp bạn nắm rõ một số chức năng cơ bản cần thiết để sau khi thiết lập xong bạn có thể sử dụng ngay.

{% hint style="danger" %}
<mark style="color:$danger;">**Lưu ý:**</mark> <mark style="color:$danger;"></mark><mark style="color:$danger;">nếu bạn không cần thiết lập ban đầu bạn có thể tắt màn hình và bỏ qua bước này. Nhưng khuyến khích bạn nên thực hiện bước này để nắm rõ cơ bản về hệ thống hơn.</mark>
{% endhint %}

### **Bước 1. Khai báo danh mục**

<figure><img src=".gitbook/assets/bước 1.png" alt=""><figcaption></figcaption></figure>

**Thực hiện như sau:**

{% stepper %}
{% step %}
Tại màn hình **Thiết lập ban đầu**, chọn mục **Khai báo danh mục**.
{% endstep %}

{% step %}
Nhấn dấu (+) tại từng danh mục để thêm mới thông tin.
{% endstep %}

{% step %}
Nhập các thông tin theo yêu cầu trên màn hình.
{% endstep %}

{% step %}
Nhấn **Lưu** để hoàn tất.
{% endstep %}

{% step %}
Tiếp tục thực hiện với các danh mục còn lại.
{% endstep %}
{% endstepper %}

Các danh mục cần khai báo:

* [<mark style="color:$primary;">**Đối tác**</mark>](danh-muc/doi-tuong/doi-tac.md): Thêm khách hàng, nhà cung cấp.
* [<mark style="color:$primary;">**Hàng hóa, vật tư**</mark>](danh-muc/hang-hoa-and-kho/vat-tu-hang-hoa-thanh-pham.md): Thêm hàng hóa, vật tư, thành phẩm.
* [<mark style="color:$primary;">**Tài khoản ngân hàng**</mark>](danh-muc/tai-chinh-ke-toan/tai-khoan-ngan-hang.md): Thêm thông tin tài khoản ngân hàng của doanh nghiệp.
* [<mark style="color:$primary;">**Kho**</mark>](danh-muc/hang-hoa-and-kho/kho.md): Khai báo các kho hàng của doanh nghiệp. (_Hệ thống sẽ tự tạo sẵn một kho đơn vị mặc định_)
* [<mark style="color:$primary;">**Nhân viên**</mark>](danh-muc/doi-tuong/nhan-vien.md): Thêm thông tin nhân viên (nếu có nhu cầu).
* [<mark style="color:$primary;">**Quy tắc kết chuyển**</mark>](danh-muc/tai-chinh-ke-toan/quy-tac-ket-chuyen.md): Khai báo quy tắc kết chuyển kế toán (nếu có nhu cầu).

{% hint style="success" %}
<p align="center"><mark style="color:$success;"><strong>Hoàn thành khi các danh mục cần thiết đã được khai báo</strong></mark></p>
{% endhint %}

### **Bước 2. Nhập số dư đầu kỳ**

<figure><img src=".gitbook/assets/Bước 2 (1).png" alt=""><figcaption></figcaption></figure>

**Thực hiện như sau:**

{% stepper %}
{% step %}
Mở mục **Nhập số dư đầu kỳ.**
{% endstep %}

{% step %}
Chọn **Nhập số dư tài khoản** để khai báo số dư các tài khoản kế toán.
{% endstep %}

{% step %}
Nhấn **Nhập số dư**, nhập số liệu theo thực tế của doanh nghiệp và lưu lại.
{% endstep %}

{% step %}
Nếu doanh nghiệp có hàng tồn kho, chọn **Nhập tồn kho**.
{% endstep %}

{% step %}
Chọn kho, hàng hóa và nhập số lượng, giá trị kho.
{% endstep %}

{% step %}
Kiểm tra và lưu thông tin.
{% endstep %}
{% endstepper %}

{% hint style="danger" %}
<mark style="color:$danger;">**Lưu ý:**</mark>

* <mark style="color:$danger;">Doanh nghiệp mới thành lập, chưa có số dư, chọn Doanh nghiệp mới, chưa có số dư. Nếu có bất kỳ thông báo nào không thực hiện tiếp được vui lòng liên hệ quản trị viên.</mark>
* <mark style="color:$danger;">Doanh nghiệp đã hoạt động, cần nhập số dư tài khoản và tồn kho (nếu có).</mark>
* <mark style="color:$danger;">Cần kiểm tra kỹ số liệu trước khi ghi sổ chứng từ đầu tiên vì sau ghi sổ, số dư đầu kỳ sẽ bị khóa và không thể chỉnh sửa.</mark>
{% endhint %}

{% hint style="success" %}
<p align="center"><mark style="color:$success;"><strong>Hoàn thành khi đã nhập số dư tài khoản và tồn kho (nếu có)</strong></mark></p>
{% endhint %}

### **Bước 3. Ghi sổ chứng từ đầu tiên**

<figure><img src=".gitbook/assets/Bước 3 (1).png" alt=""><figcaption></figcaption></figure>

**Thực hiện như sau:**

{% stepper %}
{% step %}
Mở mục Ghi sổ chứng từ đầu tiên
{% endstep %}

{% step %}
Nhấn [<mark style="color:$primary;">**Tạo chứng từ**</mark>](readme/chuc-nang-them-moi-chung-tu/) (<mark style="color:red;">**Phím tắt phím N**</mark>)
{% endstep %}

{% step %}
Chọn loại chứng từ cần lập
{% endstep %}

{% step %}
Nhập đầy đủ thông tin nghiệp vụ phát sinh.
{% endstep %}

{% step %}
Kiểm tra thông tin và định khoản kế toán.
{% endstep %}

{% step %}
Lưu và thực hiện **Ghi sổ chứng từ**
{% endstep %}
{% endstepper %}

**Mẹo tạo nhanh chứng từ bằng phím tắt**

{% hint style="danger" %}
<mark style="color:$danger;">**Lưu ý:**</mark> <mark style="color:$danger;"></mark><mark style="color:$danger;">Nên hoàn thành nhập số dư đầu kỳ trước khi ghi sổ chứng từ đầu tiên.</mark>
{% endhint %}

{% hint style="success" %}
<p align="center"><mark style="color:$success;"><strong>Hoàn thành khi chứng từ đầu tiên được ghi sổ thành công</strong></mark></p>
{% endhint %}

\- Sau khi hoàn thành các thiết lập các bước cơ bản ban đầu bạn đã có thể sử dụng hệ thống dựa trên các dữ liệu đã tạo ở các bước trên. Có thể thực hiện đóng hướng dẫn để tiếp tục sử dụng hệ thống. Hoặc khám phá hệ thống bằng các danh mục nằm bên tay trái màn hình
