# I. Màn hình tổng quan

<figure><img src="../../.gitbook/assets/màn hình tổng quan.png" alt=""><figcaption></figcaption></figure>

Các bước để vào màn hình nạp dữ liệu:

{% stepper %}
{% step %}
Ở màn hình chính, tại thanh điều hướng, chọn **“Chứng từ tổng hợp”** (<mark style="color:red;">**Ctrl + 1**</mark>).
{% endstep %}

{% step %}
Trong màn hình chứng từ tổng hợp, chọn mục **“Thao tác”** (<mark style="color:red;">**Phím F1**</mark>).
{% endstep %}

{% step %}
Trong màn hình thao tác, chọn chức năng **“Nạp dữ liệu”** (<mark style="color:red;">**Alt + I**</mark>).
{% endstep %}
{% endstepper %}

Sau khi chọn chức năng **“Nạp dữ liệu”**, hệ thống sẽ hiển thị màn hình nạp file.

<figure><img src="../../.gitbook/assets/màn hình chức năng.png" alt=""><figcaption></figcaption></figure>

**Màn hình gồm:**

{% stepper %}
{% step %}
Đường dẫn chức năng: hiển thị đường dẫn chức năng hiện tại
{% endstep %}

{% step %}
Sơ đồ các bước thực hiện import
{% endstep %}

{% step %}
Nhóm các nút chức năng nạp dữ liệu
{% endstep %}

{% step %}
Hiển thị nội dung dữ liệu, cấu hình dữ liệu import
{% endstep %}

{% step %}
Hiển thị hướng dẫn và các cảnh báo khi import
{% endstep %}
{% endstepper %}
